# 期货 MA144 安卓收线提醒 v1.6

手机版与电脑版 v1.6 的核心提醒规则一致：

- 自动读取各品种持仓量最大的实际月份合约，排除连续合约；
- 可同时选择多个合约，默认每60秒刷新；
- 60分钟K线标注的收线时间到达后再等待15秒确认，不再用“最后一根是否已存在60分钟”判断；
- 收盘上穿或下穿MA144都会发送通知；
- 通知同时显示收盘价、MA144、偏离点数、偏离ATR和策略条件判断；
- 完整策略判断包含日线MA60位置、日线MA60斜率分级、MA144方向以及0.1—0.5ATR幅度；
- “立即扫描”只显示当前交易日已经收盘的穿越；
- 支持最近30个交易日历史回放；
- 使用前台服务进行后台监控，屏幕熄灭或切换应用后仍可提醒。

## 手机使用

1. 首次打开时允许通知权限。
2. 点击“刷新主力”，选择需要监控的实际月份合约。
3. 保持均线144、刷新60秒，点击“开始后台监控”。
4. 通知栏出现“MA144收线监控运行中”即表示监控正常。
5. 不要在手机管家中强制结束应用；部分品牌手机需要允许后台运行并关闭电池优化。

本程序只提供行情提醒，不连接交易账户、不自动下单。公开行情可能延迟或暂时中断。

APK 可通过 GitHub Actions 的 `Build Android APK` 工作流构建，构建产物名称为 `futures-ma144-android-v1.6`。
